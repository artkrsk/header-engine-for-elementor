Sticky/reveal header engine for Elementor containers.

== Description ==

Turns an Elementor Container into a site header with sticky pinning and
scroll-driven reveal, powered by a zero-dependency TypeScript engine. The
visible show/hide animation is done in CSS via state classes and custom
properties — no per-frame JavaScript styling.
